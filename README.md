# Voice Local

### Обвести проблему и обратиться в Codex

Нажмите **Ctrl+Shift+F8**, кнопку с жучком в верхней панели или **«Обвести проблему»** в боковом меню. На снимке экрана можно обвести место красным, нарисовать пометку карандашом и скрыть область чёрным прямоугольником. Ctrl+Z отменяет последнюю отметку, Esc закрывает снимок.

Напишите, что исправить, и нажмите **«Отправить в Codex»** (или Ctrl+Enter). Описание поступает в подключённый чат Codex со ссылкой на локальный снимок, который агент открывает для анализа. Ответ и исправления появляются в Codex. Требуются установленный и авторизованный Codex и доступ к интернету. Записи голоса и локальные модели продолжают работать отдельно.

Подключение хранится в `codex-connection.json` в папке данных Voice Local. Копии отправленных обращений: `reports/`. Для отправки используется `codex queue`, без отдельного API-ключа. Если отправка не удалась, снимок и описание сохраняются локально, а окно позволяет повторить попытку.

Самостоятельное приложение для Windows с локальными голосовыми моделями и интерфейсом по образцу установленного VoiceOS. Для диктовки, обработки текста, чата и анализа экрана не нужны подписка, аккаунт или API-ключи.

## Запуск

После сборки откройте `release/win-unpacked/Voice Local.exe` или `Запустить Voice Local.cmd`. Модели устанавливаются отдельной командой из раздела «Исходный код и сборка» и в Git-репозиторий не входят. Переносите собранную папку `win-unpacked` целиком: один EXE без `resources` не работает. Первый запуск загружает модель в память, а не из интернета.

|Клавиши по умолчанию|Действие|
|---|---|
|Удерживать Alt + Пробел|Диктовать в активное текстовое поле; отпустить для распознавания и вставки|
|Удерживать F8|Говорить агенту; отпустить, чтобы получить голосовой ответ|
|Ctrl + Alt + V|Вставить последнюю диктовку|
|Escape во время записи/обработки|Отменить диктовку|

Кнопка диктовки в самом приложении копирует результат в буфер обмена. Автоматическая вставка по горячей клавише возвращается в исходное окно. В приложениях, запущенных от администратора, Windows может запретить вставку из обычного процесса — тогда используйте ручную вставку. Крестик сворачивает приложение в трей; выход находится в меню значка в трее.

Голосовые запросы продолжают текущий разговор. Агент отвечает по-русски и озвучивает ответы, когда включена настройка озвучивания. Если он предлагает действие, снова удерживайте F8 и скажите «да» или «нет». Новая команда может прервать предыдущую задачу; нажатие F8 также останавливает текущее озвучивание.

Команда «Вася, закрой Roblox» сначала показывает найденное окно и запрашивает подтверждение, затем закрывает его обычным способом. На «закрой» помощник уточняет приложение; при нескольких совпадениях можно ответить «закрой второй». Если программа просит сохранить документ, помощник сообщает, что окно осталось открытым. Принудительное завершение не используется.

Длинная история сокращается по настоящему счётчику токенов модели до отправки. Текущая просьба сохраняется целиком; слишком большой текущий текст вызывает понятное сообщение.

Скажите **«открой YouTube»** или просто **«YouTube»**, чтобы открыть сайт в браузере. **«Открой ссылку https://example.org»** открывает явно названный адрес. **«Открой Discord»** выбирает установленное приложение, а **«открой сайт Discord»** — веб-версию. Неизвестный сайт помощник просит назвать адресом; неподдерживаемые схемы ссылок не открывает. Каталог приложений загружается из ярлыков пользователя и [списка «Пуск» Windows](https://learn.microsoft.com/en-us/powershell/module/startlayout/get-startapps?view=windowsserver2025-ps), доступен в разделе «Приложения» и обновляется его кнопкой.

## Возможности

- Диктовка через настоящий микрофон, выбор устройства, определение языка, импорт WAV (16-bit PCM), отмена и повторное распознавание.
- Режимы без правки, лёгкой правки и редактирования; перевод; общий стиль и правила для отдельных приложений по заголовку активного окна.
- Словарь произношений, текстовые шаблоны, история с исходным текстом и аудио, поиск, удаление и экспорт.
- Локальный чат и голосовой агент с разговорами, памятью и инструкциями пользователя.
- Анализ экрана локальной визуальной моделью после включения разрешения.
- Открытие установленных и обычное закрытие запущенных приложений, открытие сайтов и HTTP(S) ссылок в браузере, управление громкостью и медиаплеером, работа с Markdown-заметками, вставка текста. Прямые команды открыть выбранный файл / названное приложение исполняются сразу; закрытие названного окна и остальные изменения требуют подтверждения.
- Русский голос Ирина через Piper, доступные системные голоса Windows, включение/выключение озвучивания.
- Подключения MCP через локальный процесс (stdio) или HTTP. Параметры задаёт пользователь; удалённый сервер может требовать сеть и собственную авторизацию.
- Светлая и тёмная темы, системная тема, автозапуск, запись при удержании или по переключению, одна верхняя панель записи и агента, резервные копии текстовых данных.

Приватный режим удаляет новые аудиозаписи, включая случаи ошибок, и не добавляет диктовки в историю. Разговоры и память агента при этом сохраняются локально. Старую историю можно удалить отдельно. JSON-копии не содержат аудиофайлов и переменных окружения подключений.

## Модели и данные

### Поиск файлов — EmbeddingGemma 2

В разделе **Файлы** выберите папки и нажмите **Обновить поиск** для поиска по содержимому. По именам и типам поиск работает сразу. Кнопки результата открывают файл, показывают его в Проводнике, читают текст или подготавливают вопрос агенту. Через F8 можно сказать: «Найди фото», затем «Открой второй файл»; «Найди приложение Дискорд», затем «Открой его»; или сразу «Открой Хром» / «Запусти калькулятор». Явная команда с однозначным названием или номером открывает объект сразу. Для неоднозначного «открой его» помощник просит выбрать номер или название. Найденные в разделе Файлы результаты тоже доступны голосовой команде открытия. Ссылки из истории восстанавливаются после перезапуска с повторной проверкой выбранной папки и существования файла.

Используется **EmbeddingGemma 2 Q8_0 GGUF**, сжатая до **309 855 456 байт (310 МБ / 296 МиБ)** версия текстового энкодера, без локального дообучения. Файл получен из репозитория ggml-org/embeddinggemma-2-GGUF; SHA-256 сверена с опубликованной. Модель работает через встроенный llama.cpp на CPU с 768 измерениями, не занимая GPU основного агента. Во время поиска облачных вызовов и загрузок нет.

Модель поиска включена в portable-папку `resources/runtime/models`, поэтому поиск работает после переноса всей папки приложения на другой ПК. Python, PyTorch и прежняя полная модель на 1,5 ГБ для поиска больше не используются. Команда `npm run configure-search` устанавливает компактный GGUF и проверяет его контрольную сумму. Параметры записаны в `resources/runtime/embedding-config.json` (в исходниках — `runtime/embedding-config.json`). При смене формата модели старый индекс автоматически помечается для пересоздания кнопкой «Обновить поиск».

По умолчанию выбраны Рабочий стол, Документы и Изображения. Поиск по именам файлов и типам (например, «все фото») работает сразу, без создания индекса и без загрузки модели. Результаты ограничены выбранными папками и лимитом обхода 4000 файлов; агент сообщает количество совпадений и частичное покрытие. Для поиска по смыслу содержимого индекс обновляется вручную; неизменённые файлы повторно не обрабатываются. Индекс хранится отдельно в `%APPDATA%/Voice Local/file-index.json` и не включается в JSON-экспорт истории. Удаление папки из списка сразу блокирует доступ к её файлам; кнопка очистки удаляет индекс. После ошибки инструмент исключается из текущего запроса, а повторный вызов завершается понятным сообщением вместо шести одинаковых ошибок.

TXT, Markdown, CSV, JSON, HTML и другие текстовые форматы, PDF и DOCX читаются по содержимому. Для изображений, видео, архивов, старых DOC/XLS и таблиц XLSX поиск идёт по имени и пути; распознавание содержимого картинок не включено. Исполняемые файлы, ссылки, скрытые/служебные папки, зависимости и известные имена файлов с секретами пропускаются. На один индекс — до 4000 файлов. Текст извлекается до 100 КБ, PDF — до 12 страниц; для смыслового поиска берутся до трёх фрагментов из начала, середины и конца текста. В интерфейсе и ответах отмечается неполное чтение. Поиск не гарантирует нахождение каждого упоминания в длинном документе.

Распознавание русского: GigaAM v3 RNNT INT8, около 225 МБ весов, через локальный ONNX Runtime на CPU. После первой загрузки модели короткие фразы обычно обрабатываются быстрее Whisper; для других языков и при ошибке GigaAM используется Whisper small multilingual через `whisper.cpp`. Агент и изображения: Qwen3.5 2B Q4_K_M с визуальным проектором, `llama.cpp`. Озвучивание русской речи: Piper Irina. GPU используется агентом через Vulkan; при неудаче приложение пробует CPU. В настройках можно выбрать совместимый файл модели распознавания и число GPU-слоёв агента.

Данные находятся в `%APPDATA%/Voice Local`. Модели — в `resources/runtime` рядом с собранным приложением; для проекта — в `runtime`. Размер приложения с моделями составляет несколько гигабайт. Основная обработка выполняется на компьютере, без телеметрии и обращения к VoiceOS.

## Отличия от VoiceOS

Это отдельная реализация, а не исходный VoiceOS с изменённой подпиской. Интерфейс следует изученной структуре VoiceOS 0.1.38, но точное совпадение каждого экрана не заявляется. Собственные серверы VoiceOS, облачная авторизация, магазин интеграций, командные аккаунты и подписки не перенесены. Gmail, Calendar и другие внешние сервисы можно подключать через совместимый MCP-сервер с собственной авторизацией; полностью офлайн они недоступны.

Маленькая локальная модель уступает крупным облачным моделям и может ошибаться в распознавании, правке, вычислениях и анализе картинок. Подтверждения защищают от выполнения непросмотренных изменений, но не делают ответы безошибочными.

## Исходный код и сборка

Требования для пересборки: Node.js, npm и .NET SDK 8 или новее. Для обычного запуска они не нужны.

```powershell
npm install
dotnet publish native/VoiceNative.csproj -c Release -r win-x64 --self-contained true -o runtime/native -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
npm run models
npm run build-asr
npm test
npm run package
```

`npm run models` устанавливает Whisper и другие исходные модели. `npm run build-asr` требует Python 3.11, скачивает только компактную GigaAM v3 INT8 и собирает автономный локальный распознаватель. Интернет нужен только для сборки. Обычное использование скачивания не требует.

Основные файлы: `electron/main.cjs` — окна и диктовка; `electron/agent.cjs` — агент и подтверждения; `electron/models.cjs` — инференс; `electron/speech.cjs` — русский голос; `native/Program.cs` — клавиатура, микрофон, вставка, звук; `src/main.jsx` и `src/style.css` — интерфейс.

## Проверка

94 автоматические проверки состояния, контекста, поиска, сайтов и действий агента; реальные проверки распознавания, GPU-инференса, вызова инструмента и анализа тестовой картинки. GigaAM v3 RNNT проверена на шести локальных тестовых записях и 12 русских командах, синтезированных Piper: все 12 команд сохранили намерение и объект, тишина осталась пустой. На английских названиях сайтов модель иногда ошибается. Качество реального микрофона зависит от шума и произношения. Проверены автономный распознаватель в собранном приложении и запасной Whisper. Сценарии находятся в `test/`, `scripts/test-command-speech.cjs` и `scripts/smoke-packaged.cjs`.

Источники компонентов и уведомления об их лицензиях: `THIRD_PARTY_NOTICES.md` и `runtime/licenses`. Исходники VoiceOS и его аккаунт в приложение не входят.
